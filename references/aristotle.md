# 亚里士多德：目的、德性与实践智慧

## 一句话

先弄清这件事“为了什么”，再问“对这个情境而言，恰到好处是什么”。

## 核心问题

- 事物的功能（ergon）与目的（telos）是什么？
- 在规则不够用的时候，有经验的人会怎么判断？

## 可操作工具

### 1. 四因分析

任何事物/做法都可以问四种原因：

- **质料因**：由什么构成？（人、钱、数据、时间）
- **形式因**：它是什么结构/定义？
- **动力因**：谁推动它发生？
- **目的因**：为了什么？

**用法**：缺哪一因，方案就会在哪一环失败。四因不是四个标签，而是四种“为什么”的回答。

### 2. 功能与目的

**追问**：这件事的 telos 是什么？它的“好”是否由功能定义？

例：一把刀的好是锋利；一个团队的好不只是和谐，而是能完成它存在的任务。

### 3. 中道

中道不是平均或折中，而是“相对于我们、由实践智慧确定的恰当”。

**做法**：先写出两个极端（过度 / 不足），再问：在这个人、这件事、这个时机下，恰当在哪？

例：勇敢是鲁莽与怯懦之间，但“中间点”因情境而变。

### 4. 实践智慧（phronesis）

规则无法穷尽情境。**追问**：

- 谁有处理类似情境的经验？
- 有哪些先例？它们与现在哪里不同？
- 如果我现在必须做，依据是什么？

实践智慧不是直觉，而是经验 + 判断 + 对目标的把握。

### 5. 德性与习惯

**追问**：要成为能稳定做出这种判断的人，需要重复什么行为、处在什么制度里？

德性是习惯性的品质，不是一次表演。

### 6. 修辞三角

说服对象时检查：

- **ethos**：他凭什么信你？（可信度、品格）
- **pathos**：他此刻的感受是什么？
- **logos**：理由是否成立？

缺一角，说服就会塌。

## 重述句式

- “这件事是为了什么？它的功能规定了好坏标准吗？”
- “在这个情境里，过度和不足分别是什么？恰当在哪？”
- “有经验的人会怎么做？规则在哪里不够用？”

## 输出模板

1. **目的**：这件事的 telos
2. **四因**：质料 / 形式 / 动力 / 目的
3. **中道**：两个极端 + 情境判断
4. **实践智慧**：先例、经验、当前判断
5. **行动**：要养成什么习惯、由谁判断、如何复盘

## 边界与误用

- 中道不是“各让一步”；有些事没有中间地带。
- 目的论不能用来为现状辩护；功能可以争议，也可以被重新定义。
- 德性伦理不替代规则与后果评估；三者要配合。
- 亚里士多德本人为奴隶制和女性地位辩护，这是历史局限，不要照单全收。

## 概念锚点

四因；telos；ergon；eudaimonia（幸福/兴盛）；德性（arete）；中道（mesotes）；实践智慧（phronesis）；akrasia（意志薄弱）；修辞三要素。
