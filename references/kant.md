# 康德：可能性条件的审查者

## 一句话

先问“这凭什么可能、凭什么正当”，再问“我该怎么做”。

## 核心问题

- 我能知道什么？（认识的界限）
- 我应当做什么？（道德的法则）
- 我可以希望什么？（目的与意义）

康德不直接给答案，而是审查答案的**条件**：经验要成立需要什么？道德判断要成立需要什么？哪些问题超出了理性的合法使用？

## 可操作工具

### 1. 前提审查

把判断拆成：经验事实 / 概念定义 / 价值预设 / 未言明条件。

**追问**：如果去掉这个假设，结论还成立吗？这个假设本身能被检验吗？

### 2. 可能性条件

**追问**：要使 X 成立，必须已经有什么？（制度、能力、共识、时间、信任）

例：要“自由签约”成立，必须先有信息对称、退出选项和可执行的法律。

### 3. 可普遍化测试

**问法**：我愿意把我此刻的准则变成所有人都遵守的法则吗？这样做会不会自相矛盾？

注意：不是问“大家都这么做会怎样”的后果预测，而是问准则本身能否被一致地意欲。

例：“缺钱时可以不告而取”一旦普遍化，“财产”与“承诺”就不复存在，行为所依赖的条件被自己取消。

### 4. 目的公式

**问法**：我是否把某人仅仅当作手段？谁的自愿、知情或拒绝被省略了？

可操作版本：列出所有受影响者，标注“知情 / 同意 / 可退出”三栏。

### 5. 界限意识

区分“可以知道”与“只能思考”：不要用经验证据去证明超验命题，也不要用超验立场逃避经验检验。

**追问**：这个争论是在经验范围内，还是双方把不同层面的问题混在一起？

## 重述句式

- “在什么条件下，这个做法才是可能的？”
- “这条准则能否被普遍化而不自我取消？”
- “谁被当成了手段，而不是目的？”

## 输出模板

1. **判断**：可行 / 不可行 / 有条件可行。
2. **条件清单**：必须成立的前提，逐条标“已满足 / 未满足 / 未知”。
3. **普遍化检验**：准则 + 矛盾点。
4. **受影响者**：谁、知情吗、能拒绝吗。
5. **行动**：补哪个条件、向谁征求同意、如何验证。

## 边界与误用

- 不是“只要动机好，后果无所谓”；康德也要求判断力与经验知识。
- 可普遍化不是万能计算器；有些准则普遍化后不矛盾但仍然卑劣，需要人性公式补位。
- 不要把所有问题都道德化；技术问题、事实问题先按事实处理。
- 不要假装能认识“物自体”；留白不是失败，是边界。

## 概念锚点

先验 / 后天；分析 / 综合；现象 / 物自体；绝对命令（普遍法则、人性公式、自律）；义务 vs 偏好；二律背反；启蒙（公开运用理性）。
