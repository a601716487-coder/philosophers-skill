# 概念澄清工作流

## 触发

一个词被反复使用但理解不一：定义之争、术语打架、文档/PRD 里说不到一起去。

## 输入

- 必须：要澄清的概念、争议双方的用法（或至少一方）。
- 最好有：真实例句、边界案例、这个概念的用途。

## 步骤

1. **收集用法**（读 `../references/wittgenstein.md`）
   - 写 5 个真实例句，2 个可疑/边界例句。
   - 谁在什么场合对谁用？用了之后发生什么（承诺、授权、拒绝）？

2. **语言游戏对照**：双方各自的目的、规则、胜负标准是否相同？是否混用了两个游戏？

3. **家族相似**：这个概念有无单一本质？列出范例网络，找出重叠与反例。

4. **康德：前提与条件**（读 `../references/kant.md`）
   - 这个概念的成立依赖哪些前提？经验定义 vs 规范定义。
   - 双方是事实分歧、价值分歧，还是纯粹的定义分歧？

5. **伪问题检测**：把关键词拿掉，还剩什么经验问题？谁能给出可检验答案？

6. **下操作性定义**：写一个“可观察、可判定、带边界”的定义，并注明它的用途范围。

7. **成文**：填充 `../templates/concept-note.md`。

## 产出

`../templates/concept-note.md`

## 质量门

- [ ] 定义可操作：能根据它判定一个案例属于 / 不属于。
- [ ] 标出了边界案例与裁决方式。
- [ ] 明确了这是“澄清”不是“替大家做价值选择”。
- [ ] 保留了原始分歧点，没有假装统一。
