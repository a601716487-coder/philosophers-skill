# 批判工作流

## 触发

要对一个已有方案、战略、产品、政策做批评：它行不行、哪里会崩、给谁带来代价。

## 输入

- 必须：被批判对象的文本或描述、它的目标。
- 最好有：它的作者/受益者、数据或证据、时间与预算约束。

## 步骤

1. **复述**：用中性语言把对象复述一遍，并写下它自己的成功标准。先不评价。

2. **黑格尔：内在批判**（读 `../references/hegel.md`）
   - 进入它的逻辑，推到极端，看它是否自我瓦解。
   - 它抓住的“真理环节”是什么？它预设了什么？

3. **马克思：结构与成本**（读 `../references/marx.md`）
   - 谁受益、谁承担成本？成本是否被转移或隐藏？
   - 什么关系被商品化？哪些“普遍利益”其实是特殊利益？

4. **福柯：话语与规训**（读 `../references/foucault.md`）
   - 谁有资格定义问题？谁被定义成问题？
   - 靠哪些测量 / 分类 / 指标运作？要求人成为什么主体？
   - 抵抗在哪、被如何命名？

5. **合成**：区分三类批评——事实错误、逻辑矛盾、价值/权力后果。三类不要混写。

6. **成文**：填充 `../templates/critique-memo.md`，必须给出“什么条件下我们会改变结论”。

## 产出

`../templates/critique-memo.md`

## 质量门

- [ ] 批判建立在复述之上，没有歪曲对象（先写对方最有力的版本）。
- [ ] 事实批评与价值批评分开标注。
- [ ] 每条批评都落到“证据 / 条件”，不是情绪。
- [ ] 给了替代方案或最小改进，没有只拆不建。
- [ ] 写清“在什么条件下我会改口”。
