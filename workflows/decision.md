# 决策工作流

## 触发

要做决定：要不要做某件事、多个方案选哪个、该不该接受某个条件。

## 输入

- 必须：要决定的问题、可选方案（≥2 个）、截止时间。
- 最好有：受影响者名单、约束（预算/法规/时间）、可逆性、失败代价。

## 步骤

1. **摆事实（先不动理论）**：写清已知 / 未知 / 假设；列出全部方案，不评价。

2. **康德：条件与正当性**（读 `../references/kant.md`）
   - 每个方案的前提是否成立？（前提审查）
   - 把准则普遍化，看是否自我取消？（可普遍化测试）
   - 谁被只当手段？知情、同意、可退出吗？（目的公式）

3. **亚里士多德：目的与落地**（读 `../references/aristotle.md`）
   - 这件事的 telos 是什么？功能定义好坏。
   - 四因缺哪一因？
   - 过度 / 不足的极端在哪，情境里的恰当在哪？
   - 谁有经验？先例如何？

4. **黑格尔：张力与扬弃**（读 `../references/hegel.md`）
   - 每个方案的“真理环节”是什么？
   - 各自推到极端会怎样？矛盾在哪？
   - 有无方案能取消坏处、保存好处、上升到更高层次？

5. **法庭合成**：按 SKILL.md“法庭模式”合并三个透镜的判断，标出共识与真分歧。

6. **成文**：填充 `../templates/decision-memo.md`。

## 产出

`../templates/decision-memo.md`

## 质量门

- [ ] 每个方案都过了康德 + 亚里士多德 + 黑格尔三步，没有跳过。
- [ ] 事实与价值分开标注，未知已写“未知”。
- [ ] 给了一个可逆的最小行动，而不是只有一个大结论。
- [ ] 写了最强的反方意见及其触发条件。
