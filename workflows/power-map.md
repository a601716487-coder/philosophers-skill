# 权力与变革工作流

## 触发

一个变革推不动、一个决策反复被卡、想搞清楚组织里谁在起作用、为什么有些人没声音。

## 输入

- 必须：要推动的变革或要分析的议题。
- 最好有：利益相关者名单、会议/决策记录、组织结构。

## 步骤

1. **问题化**（读 `../references/foucault.md`）：这个议题何时被当成“问题”？谁在推动它成为问题？

2. **话语地图**：谁有资格发言？什么算“专业/理性”，什么被归为“情绪/不专业”？谁被看见、谁被忽略？

3. **马克思：结构定位**（读 `../references/marx.md`）：资源/决定权/风险/剩余各归谁？规则由谁定、争议由谁裁？

4. **福柯：规训装置**（读 `../references/foucault.md`）：时间表、空间、考核指标、可见性、正常/异常的界线各是什么？

5. **黑格尔：承认与矛盾**（读 `../references/hegel.md`）：各方要的“承认”是什么？真正不可调和的矛盾在哪？

6. **合成**：画出“权力地图”——正式权力、非正式影响、被排除的声音、抵抗点。

7. **成文**：填充 `../templates/council-report.md`，给一个最小、可逆、合伦理的推动动作。

## 产出

`../templates/council-report.md`

## 质量门

- [ ] 区分了“正式权力”与“非正式影响”，不只看组织架构图。
- [ ] 明确写出了“谁被排除、谁没声音”。
- [ ] 结论不是阴谋论，落到可观察的装置与实践。
- [ ] 推动动作合伦理，不以操纵为手段。
