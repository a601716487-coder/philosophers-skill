# 价值与激励审计工作流

## 触发

团队没动力、文化口号与行为不符、激励设计失效、倦怠，或想审查一套价值观是否还成立。

## 输入

- 必须：要审计的价值/激励制度、它宣称的目标。
- 最好有：真实行为数据、员工反馈、历史沿革。

## 步骤

1. **清点**：列出正式价值观 / 激励规则，以及现实中实际被奖励的行为。两边各列一张表。

2. **尼采：谱系与动机**（读 `../references/nietzsche.md`）
   - 这套价值谁提出的、反抗什么？
   - 它驱动的是“创造”还是“怨恨 / 防御”？
   - 用永恒轮回测试：如果这套价值要无限重复，人还愿意吗？

3. **马克思：利益与异化**（读 `../references/marx.md`）
   - 谁从现行激励里受益？谁承担成本？
   - 哪些价值被商品化 / 指标化后失真？
   - 员工与产品、过程、他人、自身的关系是否被切断？

4. **亚里士多德：目的与德性**（读 `../references/aristotle.md`）
   - 这套价值服务于什么 telos？
   - 它培养的是“一次性表演”还是稳定的习惯/德性？
   - 过度与不足在哪，恰当在哪？

5. **对齐判断**：宣称价值 vs 实际奖励的差距是什么造成的？（设计错误、结构矛盾，还是表里不一）

6. **成文**：填充 `../templates/council-report.md`，给出可改的激励规则。

## 产出

`../templates/council-report.md`

## 质量门

- [ ] 宣称价值与实际奖励分列两表，差距被明确指出。
- [ ] 每条结论区分了“动机”“利益”“德性”三个层面。
- [ ] 给了具体可改的规则或指标，而不是口号。
- [ ] 承认了哲学无法单独回答的度量问题。
