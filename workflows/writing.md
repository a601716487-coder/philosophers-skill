# 文本与论证工作流

## 触发

一篇文章、PRD、提案、报告写不好：论证不成立、逻辑跳、概念含糊、说服不了人。

## 输入

- 必须：待改文本 + 它的目标读者与目的。
- 最好有：文本想达成的行动。

## 步骤

1. **重构论证**：抽出全部主张，标出结论、前提、证据、隐含假设。画一张论证链。

2. **亚里士多德：修辞三角**（读 `../references/aristotle.md`）
   - ethos：读者凭什么信作者？
   - pathos：读者的处境与情绪？
   - logos：论证链在哪一环断掉？

3. **维特根斯坦：概念与语言游戏**（读 `../references/wittgenstein.md`）
   - 关键词是否含糊、漂移？换个词，论点是否塌掉？
   - 有没有把两个语言游戏混用？有没有伪问题？

4. **尼采：价值与口吻**（读 `../references/nietzsche.md`）
   - 文本背后的价值从哪来、服务谁？
   - 是创造性的表达，还是在防御 / 证明“他们错了”？
   - 哪些句子是断言，哪些是真论证？

5. **重写**：给出两版——最小改动版与重构版，各自标注改了什么、为什么。

6. **成文**：填充 `../templates/critique-memo.md`。

## 产出

`../templates/critique-memo.md`

## 质量门

- [ ] 论证链画出来了，断点被指出。
- [ ] 每个修改都写清“为什么”，不是纯风格替换。
- [ ] 概念含糊处被点明，并给出可操作定义。
- [ ] 提供了最小改动版，尊重原文意图。
